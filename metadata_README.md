# Data provenance — `metadata/`

## Summary

This project is a **same-data reanalysis**. It does **not** redistribute the raw
neuroimaging data. The imaging data were obtained from two public OpenNeuro
datasets released by the original authors (Bezmaternykh et al., 2021). The files
under `metadata/` are **derived, de-identified tabular metadata** (e.g.,
per-subject identifiers of the form `sub-XX`, group labels, and scan-level
summaries) generated by this project's code from those public sources. No raw
MRI/fMRI volumes are stored in this repository.

## Original data sources

| Study | OpenNeuro accession | Content | Link |
|---|---|---|---|
| Study 1 (cross-sectional) | **ds002748** | Resting state, closed eyes; 51 patients with mild-to-moderate depression, 21 healthy controls | https://openneuro.org/datasets/ds002748 |
| Study 2 (longitudinal) | **ds003007** | Two resting-state sessions (~2-month interval); no-treatment, CBT, and fMRI-neurofeedback groups | https://openneuro.org/datasets/ds003007 |

Dataset DOI (Study 1): https://doi.org/10.18112/OPENNEURO.DS002748

Associated publication:
Bezmaternykh, D. D., Melnikov, M. Ye., Savelov, A. A., Kozlova, L. I.,
Petrovskiy, E. D., Natarova, K. A., & Shtark, M. B. (2021). Brain networks
connectivity in mild to moderate depression: resting state fMRI study with
implications to nonpharmacological treatment. *Neural Plasticity*, 2021,
8846097. https://doi.org/10.1155/2021/8846097

## Licensing and reuse of the source data

The OpenNeuro datasets are openly available without access restriction. OpenNeuro
distributes datasets under a **CC0 1.0 public-domain dedication** unless a dataset
states otherwise; users should confirm the licence shown on each dataset's
OpenNeuro page at time of download. The derived metadata in this repository are
provided only to document and reproduce the analysis and are subject to this
repository's own licence (see `LICENSE.txt`).

## What is and is not shared here

- **Included:** derived, de-identified tabular metadata produced by this project's
  scripts (subject-level identifiers `sub-XX`, group/session labels, motion and
  scan-level summaries).
- **Not included:** any raw or preprocessed MRI/fMRI image data. These must be
  obtained directly from OpenNeuro at the links above.

## How to cite

If you use these data, please cite **both** the original OpenNeuro dataset(s) and
the associated publication above, in addition to this repository (see
`CITATION.cff`).

## Privacy note

The identifiers used here (`sub-XX`) are the de-identified codes assigned by the
original OpenNeuro release and do not identify individual participants. No
personally identifying information is stored in this repository.
